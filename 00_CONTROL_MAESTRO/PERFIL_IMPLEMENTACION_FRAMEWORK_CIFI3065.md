# Perfil de Implementación del Framework — CIFI 3065 Materia Mundi
**Versión:** 1.0 inicial

## Configuración
- Nivel: **N3 Avanzado**.
- Caleidoscopio rector: **C5 Pedagógico**.
- Investigador Transdisciplinario: alto.
- Artista Transdisciplinario: activación proporcional, especialmente storytelling/avatares/multimodalidad.
- Programador Humanista: activación por necesidad educativa/infraestructura/aplicación.
- C4 Integral: posible, no permanente; requiere necesidad que justifique integración de los tres perfiles.

## Regla pragmática
El Caleidoscopio orquesta perfiles; no añade una cuarta metodología. Se activa lo necesario para producir evidencia y aprendizaje, no para maximizar complejidad.

## Aplicaciones educativas
Si emerge una necesidad educativa que justifique software propio, baseline inicial:
**Human-Centered + Local-First + SDD + Security by Design + Security by Default + OOP**, con especificación, pruebas, revisión humana, documentación y gate.

## Capas
1. Framework = infraestructura de proyecto.
2. Protocolo de Virtualización = proceso curricular F1–F10.
3. PSEC/REC = coherencia pedagógica.
4. PROEMA = modelo de investigación.
5. Protocolo de Sesión = continuidad operativa.
6. Metodología StoryLab = estándar técnico inicial sólo cuando se construya software.
