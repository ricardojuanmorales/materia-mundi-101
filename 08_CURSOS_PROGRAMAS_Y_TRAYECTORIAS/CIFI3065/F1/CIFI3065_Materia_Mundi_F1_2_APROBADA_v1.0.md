# CIFI 3065 Virtual — Materia Mundi
## F1.2 — Diagnóstico pedagógico y tecnológico: diseño de línea base para primera implementación
**Versión:** v1.0 aprobada · **Fecha:** 19 agosto 2026 · **Estado:** 🟡 Diseño completado / implementación y validación empírica diferidas.

CIFI 3065 nunca se ha ofrecido en esta modalidad. Por ello, F1.2 no presume datos de una cohorte virtual previa. Se completa la capa de diseño diagnóstico y se difiere la capa empírica a la primera oferta.

### Producto tangible
Instrumento diagnóstico docente/estudiantil; variables de competencia digital/LMS, acceso, conectividad, dispositivos, tiempo, accesibilidad/diversidad, preparación científico-investigativa e IA responsable; matriz de tabulación; plantilla de Perfil de Entrada; registro de apoyos/contingencias; protocolo de interpretación.

### Gate diferido
Primera oferta: administrar → analizar → Perfil de Entrada → apoyos → ajustes → registro de evidencia.

**Regla:** la ausencia actual de datos empíricos se registra como evidencia de implementación no disponible todavía, no como fracaso de diseño.

### Bitácora — Entrada 008A
F1.2 queda aprobada como diseño de línea base. Implementación y validación empírica pasan al registro de asuntos diferidos y se activarán en la primera oferta.
