## 1. Motivo

La sesión detectó una tensión legítima: F8 había avanzado con fuerza en gobernanza, trazabilidad y arquitectura operacional, pero todavía no hacía suficientemente visible el producto directamente utilizable para montar el curso en el LMS.

Se concluye que el producto integrado operativo de F8 debe expresarse como un **Guión Maestro de Montaje G4 vivo**, iniciado en H2, enriquecido en H3–H5 y consolidado en H6 junto al MVP operacional, expediente verificable y Documento Maestro F8.

## 2. Decisiones humanas ratificadas

### D8-R01 — Producto central F8

**Decisión: C.** El Guión Maestro de Montaje G4 será un producto vivo desde H2, enriquecido progresivamente por H3–H5 y congelado/consolidado en H6.

### D8-R02 — Umbral de cierre G4

**Decisión: C.** Un objeto puede cerrar F8 si está montado o si existe un slot G4 completamente especificado. Las decisiones sustituibles pueden quedar para el montaje unitario final.

Estados auxiliares:
- **G4-A:** objeto montado/verificable;
- **G4-B:** slot completamente especificado;
- **G4-C:** decisión sustituible durante montaje, con función y criterio ya resueltos.

### D8-R03 — Corrida salvaje y F9

**Decisión: D.** Se utilizará baseline anónimo + registro separado de señales pre-F9. Estas señales pueden orientar F8, pero no se contarán automáticamente como validación formal F9.

### D8-R04 — Núcleo común de unidades históricas

**Decisión: C.** Cada unidad histórica tendrá un núcleo común robusto con la secuencia pedagógica esencial y puntos internos para activar apoyo, ruta base o profundización.

Gramática candidata:
`orientación → problema → FEHE → evidencia/fuente primaria → experiencia → REC → continuidad`

### D8-R05 — Simetría FEHE

**Decisión: C.** FEHE opera como gramática recurrente reconocible con intensidades variables según el fenómeno histórico, evitando uniformidad mecánica.

### D8-R06 — Intensidades adaptativas

**Decisión: D.** Se preservan REC, función y criterio esencial. Varían principalmente andamiaje, autonomía, contexto, complejidad opcional y profundidad de exploración.

### D8-R07 — Selección de ruta

**Decisión: D.** Autoselección guiada y reversible en cada unidad, sin etiquetar estudiantes ni fijar identidades académicas.

Lenguaje recomendado:
- necesito una guía adicional;
- estoy listo para continuar;
- quiero llevar esto más lejos.

### D8-R08 — Puertos adaptativos G4

**Decisión: D.** Una sola unidad común incorporará puertos adaptativos en momentos estratégicos, en vez de tres versiones completas o tres módulos separados.

### D8-R09 — Profundización

**Decisión: D.** La profundización amplía agencia y sofisticación, pero normalmente reutiliza el mismo REC o lo enriquece sin crear automáticamente otra obligación evaluativa.

## 3. Interpretación metodológica

No se utilizarán categorías fijas de “rezagado/normal/destacado”. Se reconocen necesidades y estados variables dentro de cada experiencia. Una misma persona puede necesitar más apoyo en una unidad y escoger mayor autonomía o profundización en otra.

La adaptabilidad queda definida como:

`núcleo común sólido + movilidad reversible + variación de andamiaje/autonomía/profundidad + REC/criterio preservado`

Esto protege dignidad académica, equivalencia y agencia.

## 4. Consecuencias para H2–H6

- **H2:** debe producir arquitectura LMS + primera estructura del Guión Maestro + gramática común adaptable.
- **H3:** añade evaluación, rúbricas, gradebook, feedback y recuperación al Guión.
- **H4:** añade interacción, presencia y continuidad PROEMA/REC.
- **H5:** añade accesibilidad, variantes, recursos, medios, tecnología, QM-B y slots finales.
- **H6:** consolida Guión Maestro de Montaje G4 v1.0 + Auditoría Sistémica + Documento Maestro + Gate F8→F9.

## 5. Contrato Mínimo G4

Todo slot G4-B/C debe especificar, como mínimo:

`función → estudiante/acción → entrada → contenido/tipo → REC/evidencia → criterio → ubicación → accesibilidad → dependencia → estado → decisión pendiente → criterio de sustitución`

Un placeholder vacío no satisface F8.

## 6. Perfil inicial / baseline

Se prefiere un **baseline anónimo funcional** a un perfil fijo de estudiante.

Propósito:
- conocer condiciones de acceso/aprendizaje;
- orientar apoyos;
- anticipar fricción;
- crear baseline para futura F9;
- minimizar datos personales.

No se utilizará para clasificar estudiantes en rutas permanentes.

## 7. Dictamen de reflexión

La reflexión se considera **CONVERGENTE / SUFICIENTE PARA PROCEDER**.

No quedan preguntas estratégicas bloqueantes para reorientar H2 y abrir el Guión Maestro de Montaje G4 como producto vivo.
