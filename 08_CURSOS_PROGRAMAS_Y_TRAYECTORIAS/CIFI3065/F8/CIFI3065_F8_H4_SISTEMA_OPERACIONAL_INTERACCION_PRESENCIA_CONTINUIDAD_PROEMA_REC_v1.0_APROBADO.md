## 2. Arquitectura aprobada

H4 materializa en G4 la interacción, presencia y continuidad longitudinal mediante la cadena:

`problema → evidencia → interacción con función → respuesta sustantiva/presencia → feedback/contraste → recuperación → continuidad PROEMA/REC`

Quedan vinculantes:
- interacción ≠ participación mecánica;
- presencia ≠ volumen de mensajes;
- foro ≠ publicar + responder por cumplir;
- PROEMA permanece una investigación longitudinal única;
- REC conserva progresión cognitiva reconocible;
- feedback social tiene destino posterior;
- colaboración se activa por función, no por cuota;
- H1 y H10 permanecen integrados;
- apoyo/base/profundización no infla obligación social.

## 3. Patrones aprobados

- Foro H1–H10 con problema, evidencia, razonamiento, aportación sustantiva, función social, criterio, valor, feedback y destino.
- Presencia docente por escala `cohorte → grupo → individuo`, suficiente y oportuna.
- PROEMA: `tema → subgrupo → contribución individual → E1 → E2 → E3 → E4 → E5 → presentación grupal → artículo individual → U15`.
- REC: `observar → registrar → transformar → medir → cuantificar → clasificar/representar → modelar → inferir → instrumentar → evaluar consecuencias`.
