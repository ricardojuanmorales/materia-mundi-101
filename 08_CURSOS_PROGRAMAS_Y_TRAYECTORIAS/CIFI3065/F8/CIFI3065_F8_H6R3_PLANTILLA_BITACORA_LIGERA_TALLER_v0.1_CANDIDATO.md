# CIFI 3065 Virtual — Materia Mundi
# F8 H6-R3.4 — Plantilla Bitácora Ligera de Taller

**Versión:** 0.1 CANDIDATO  
**Estado:** PLANTILLA CANDIDATA / NO CANÓNICA

La Bitácora Ligera no transcribe la conversación. Registra únicamente decisiones, hallazgos, excepciones, QA y aprendizajes significativos.

| Momento | Decisión / hallazgo | Tipo | Razón | Impacto | Acción siguiente |
|---|---|---|---|---|---|

**Tipos**
- D = decisión
- H = hallazgo
- A = ámbar
- R = rojo/F-P
- QA = defecto/corrección
- M = aprendizaje metodológico

## Registrar cuando
- se elige entre alternativas materialmente distintas;
- cambia una decisión práctica importante;
- aparece una excepción;
- se detecta una regresión;
- QA obliga a corregir;
- surge un aprendizaje útil para Expediente/protocolo.

## No registrar por defecto
- cada intercambio;
- cada frase redactada;
- cambios cosméticos;
- opciones descartadas sin consecuencia;
- pasos automáticos ya determinados.

> **La bitácora conserva decisiones, no ruido conversacional.**
