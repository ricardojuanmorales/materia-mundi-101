## 3. Plantilla madre H1–H10, capa H5

### A. Apertura / ubicación
Usar estructura semántica, navegación clara, copy que no dependa solo de visualidad y acceso persistente.

### B. Presentación FEHE
Estado típico G4-B/C. Debe declarar función, modalidad principal, alternativa lineal/accesible, procedencia, atribución y criterio de sustitución.

### C. Fuente primaria
Estado típico G4-C hasta selección humana. Contrato mínimo:
`procedencia → pertinencia → legibilidad/extensión → licencia/uso → accesibilidad → vínculo REC/evidencia → sustitución`.

### D. Puerto adaptativo
La variante de apoyo o profundización conserva REC, criterio, función, dignidad y autoría.

### E–H. Experiencia / REC / Foro / PROEMA
Verificar que herramienta, archivo, interacción y entrega sean operables y tengan alternativa legítima cuando exista barrera. El medio no redefine evidencia.

### I. Recursos Núcleo
Solo necesarios. Deben tener acceso/procedencia suficientes y contingencia si son externos.

### J. Profundización
Claramente no obligatoria. Puede ampliar contexto, historiografía, segunda fuente o apoyo sin crear crédito/tarea por defecto.

### K. Exploración
Opcional. Registrar procedencia y evitar convertir abundancia de enlaces en falsa orientación.

### L. Videoteca / medios
Cada medio debe declarar `función → jerarquía → accesibilidad → licencia/procedencia → alternativa/contingencia`.

### M. Continuidad
Las rutas de recuperación deben sobrevivir a sustitución de medio/plataforma.

### N. QA / montaje
Aplicar PH2–PH5 pertinentes y registrar evidencia EO.

## 4. Patrón de equivalencia

Para una variante:
`barrera → alternativa → REC → criterio → función → autoría → dignidad → prueba`

No aprobar variante cuyo éxito dependa de un desempeño intelectualmente inferior al recorrido principal.

## 5. Recursos y medios por unidad

Para cada Hx reservar, según pertinencia:
- 1 o más recursos Núcleo estrictamente necesarios;
- Profundización seleccionada;
- Exploración opcional;
- presentación/interfaz FEHE;
- al menos una fuente primaria representativa cuando la arquitectura histórica lo requiera;
- videoteca/archivo/museo/visualización solo si aporta función.

La selección final puede permanecer G4-C cuando el criterio de sustitución está completo y no difiere una decisión pedagógica estructural.

## 6. Registro de recurso

`ID → unidad → jerarquía → título/tipo → función → procedencia → licencia/uso → enlace/localización → accesibilidad → contingencia → fecha/estado de verificación → decisión pendiente`

## 7. Tecnología e IA

Para cada herramienta:
`función → REC → ventaja → barrera → datos → proveedor/dependencia → portabilidad → contingencia → soporte → decisión`

Para IA añadir:
`uso permitido → límite → autoría humana → verificación → transparencia/atribución → datos → alternativa sin IA → contingencia`.

No introducir IA como requisito por novedad ni como autoridad de contenido.

## 8. Privacidad

Principio de montaje:
`dato mínimo → propósito explícito → exposición mínima → alternativa razonable`.

El baseline anónimo/pre-F9 no se usa para asignar identidades/rutas permanentes ni para ampliar captura de datos.
