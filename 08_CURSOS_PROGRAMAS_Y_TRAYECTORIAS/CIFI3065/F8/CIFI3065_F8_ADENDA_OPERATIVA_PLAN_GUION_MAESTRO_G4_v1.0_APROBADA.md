## 3. Umbral G4 expedito

F8 puede considerar un objeto operacionalmente resuelto mediante:

- **G4-A — MONTADO:** implementado y disponible para verificación;
- **G4-B — SLOT ESPECIFICADO:** contenido final pendiente, pero función, ubicación, requisitos y criterio de aceptación definidos;
- **G4-C — DECISIÓN SUSTITUIBLE:** selección final diferida al montaje unitario, sin afectar arquitectura, REC, criterio ni función.

G4-B/C no equivalen a deuda pedagógica si cumplen el Contrato Mínimo G4.

## 4. Contrato Mínimo G4

Todo objeto/slot debe registrar según pertinencia:

`ID → función → acción estudiantil → entrada → contenido/tipo → REC/evidencia → criterio → ubicación LMS → nivel T8 → accesibilidad/equivalencia → dependencias → estado G4 → decisión pendiente → criterio de sustitución → prueba → destino`

## 5. Gramática adaptable para H1–H10

Núcleo común robusto:

`orientación → problema → FEHE → evidencia/fuente primaria → experiencia → REC → continuidad`

Bloques condicionales según función:

`foro | laboratorio | presentación interactiva | videoteca | mapa | visualización | simulación | PROEMA | feedback | profundización | exploración`

No se exige que todos los bloques aparezcan en todas las unidades.

## 6. Simetría FEHE

FEHE funciona como gramática recurrente reconocible, no como plantilla mecánica. Cada unidad puede variar medio, intensidad y secuencia local sin perder la simetría conceptual del curso.

## 7. Adaptabilidad sin etiquetado

Las rutas no clasifican estudiantes. Se diseñan puertos adaptativos reversibles:

- **Apoyo:** contexto adicional, ejemplos, pasos, glosario, visualizaciones o fuente anotada;
- **Base:** recorrido principal suficiente;
- **Profundización:** mayor autonomía, fuentes adicionales, controversias, conexiones transdisciplinarias o expansión opcional.

Principio vinculante:

`mismo REC/función/criterio esencial → diferente andamiaje/autonomía/profundidad`

## 8. Recursos históricos G4

Cada unidad histórica podrá reservar, según pertinencia:
- presentación interactiva FEHE;
- fuente primaria representativa;
- experiencia/laboratorio;
- foro/interacción;

- conexión PROEMA;
- recursos Núcleo;

- Exploración;

- continuidad/recuperación.

Los medios concretos pueden quedar G4-B/C cuando estén pedagógicamente especificados.
