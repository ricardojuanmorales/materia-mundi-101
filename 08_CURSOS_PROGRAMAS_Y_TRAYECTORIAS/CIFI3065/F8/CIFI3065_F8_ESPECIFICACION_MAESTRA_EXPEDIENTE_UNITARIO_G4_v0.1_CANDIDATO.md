## 1. Propósito

Definir la unidad documental mínima autosostenida para montar, verificar, mantener y auditar cada U1–U15 de Materia Mundi en granularidad G4.

Un Expediente Unitario G4 no es un plan de clase ni una ficha de resumen. Es el **plano constructivo pedagógico-operacional** de una unidad.

## 2. Definition of Done del expediente

Un expediente está suficientemente especificado cuando una persona competente puede:
1. comprender la función de la unidad dentro del semestre;
2. montar su estructura en el LMS;
3. producir o seleccionar los objetos pendientes sin reinterpretar la pedagogía;
4. configurar evaluación, feedback e interacción;
5. implementar variantes equivalentes;
6. registrar recursos, licencias y tecnología;
7. ejecutar QA y reconocer F-T/F-P;
8. conectar la unidad con las trayectorias longitudinales;
9. distinguir qué está G4-A/B/C;
10. preservar preguntas F9 sin consumirlas.

## 3. Plantilla maestra

### A. Identidad y genealogía
- ID de unidad;
- nombre;
- correspondencia H si aplica;
- función sistémica;
- NLEP/firma heredada cuando aplique;
- documentos fuente F1–F8;
- decisiones/IDs CP7, G7, VD8 y QM-B aplicables.

### B. Posición longitudinal
- qué recupera;
- qué transforma;
- qué deja preparado;
- U1/U2/U13/U14/U15 activas y con qué intensidad;
- relación PROEMA/REC/DR.

### C. Experiencia estudiantil
- apertura visible;
- pregunta rectora;
- transformación esperada;
- objetivos operacionales;
- recorrido paso a paso;
- evidencia(s) que produce;
- evidencia(s) que recupera.

### D. Plano LMS
Registrar cada objeto con ID unitario:
`ID → tipo LMS → nombre visible → ubicación → prerrequisito → acción → evidencia → criterio → visibilidad → dependencia → estado G4`.

Tipos posibles: página, módulo, archivo, enlace, foro, tarea, quiz/diagnóstico, rúbrica, gradebook item, feedback object, visualización, herramienta, recurso externo.

### E. Copy estudiantil
Para cada objeto significativo:
- título visible;
- propósito;
- instrucción;
- criterio de éxito;
- transición/qué sigue;
- lenguaje de apoyo/profundización cuando aplique.

No exige pulido editorial final si el objeto es G4-B, pero sí suficiente contenido para que la función sea inequívoca.

### F. FEHE
- función de la interfaz/presentación;
- pregunta/lente;
- objetos históricos;
- secuencia narrativa/analítica;
- qué no debe sustituir;
- modalidad principal;
- alternativa accesible;
- fuentes/proveniencia;
- estado G4.

### G. Fuente primaria / evidencia histórica
Para cada fuente central:
`ID → candidato concreto o slot → función → selección/fragmento → procedencia → autoría → fecha/contexto → licencia/uso → accesibilidad → relación REC → criterio de sustitución → estado`.

### H. Experiencia/Laboratorio
- función;
- fenómeno/operación;
- modalidad física/simulada/otra;
- secuencia;
- evidencia producida;
- seguridad cuando corresponda;
- variante equivalente;
- contingencia;
- dependencia tecnológica;
- carga.

### I. REC
- competencia dominante;
- prompt exacto candidato;
- evidencia;
- criterio;
- rúbrica;
- límite/incertidumbre;
- mejora/prueba;
- conexión posterior.

### J. Foro/interacción
- problema/prompt candidato;
- evidencia exigida;
- razonamiento esperado;
- función del par;
- aportación sustantiva;
- criterio/rúbrica;
- puntos;
- presencia docente;
- feedback;
- reutilización.

### K. PROEMA/DR
Cuando aplique:
- estado anterior;
- insumos recuperados;
- operación intelectual nueva;
- evidencia/producto;
- feedback recuperado;
- autoría;
- uso IA permitido/límites;
- puntos/categoría;
- siguiente estado.

### L. Evaluación y gradebook
`objeto → evidencia → criterio → instrumento → puntos → categoría 75/25 → visibilidad estudiante → feedback → recuperación → configuración LMS`.

### M. Feedback y presencia
- escala cohorte/grupo/individuo;
- momento;
- función;
- plantilla/copy cuando corresponda;
- qué puede apoyar IA/máquina;
- qué requiere autoridad humana;
- destino del feedback.

### N. Recursos
Separar:
- Núcleo;
- Profundización;
- Exploración;
- FEHE/media;
- fuente primaria;
- videoteca/archivo/museo;
- simulador/visualizador.

Cada recurso importante registra función, procedencia, licencia, enlace/localización, accesibilidad, contingencia y estado.

### O. Adaptabilidad
- núcleo común;
- puerto de apoyo;
- ruta base;
- puerto de profundización;
- regla de autoselección reversible;
- REC/criterio invariantes;
- carga adicional opcional claramente separada.

### P. Accesibilidad/equivalencia
`barrera → objeto → alternativa → REC → criterio → autoría → dignidad → prueba → estado`.

Incluir estructura, teclado/foco, contraste, alt, subtítulos/transcripción, visualidad exclusiva, archivos, enlaces e instrucciones según pertinencia.

### Q. Tecnología, IA, datos y privacidad
Por herramienta:
`función → ventaja → datos → dependencia → barrera → alternativa → portabilidad → contingencia → soporte → decisión`.

IA:
`uso permitido → límite → autoría → verificación → transparencia → datos → alternativa sin IA`.

### R. Carga desglosada
Tabla por bloque con minutos Núcleo y opcionales. Total ≤ techo heredado.

### S. Inventario G4 unitario
IDs `Uxx-G4-01...` con A/B/C, dependencia, evidencia EO, prueba, decisión y sustitución.

### T. QA y aceptación
Checklist mínimo:
- navegación;
- pregunta/propósito;
- evidencia;
- criterio visible;
- evaluación/gradebook;
- feedback/destino;
- interacción funcional;
- REC;
- continuidad PROEMA cuando aplique;
- accesibilidad/equivalencia;
- recurso/proveniencia/licencia;
- tecnología/contingencia;
- autoría/IA;
- carga;
- CP7/G7/VD8;
- G4-A/B/C correctamente clasificados.

### U. F-T / F-P
Registrar defectos técnicos corregibles y contradicciones pedagógicas que requieren gobernanza.

### V. F9 reservado
Lista explícita de variables/hipótesis que F8 no interpreta empíricamente.

### W. Dictamen unitario
`MONTABLE / MONTABLE CON SLOTS / REQUIERE DECISIÓN / NO MONTABLE` + condiciones.

## 4. Regla de referencias

El expediente puede referenciar registros transversales para evitar duplicación, pero nunca depender de una cadena documental tan larga que impida reconstruir la unidad.

Regla práctica:

> **Referenciar para mantener; resumir lo suficiente para montar.**

## 5. Regla de variación

U1, H1–H10, U13, U14 y U15 pueden usar subsecciones distintas. No se fuerza un bloque irrelevante sólo para completar plantilla.
