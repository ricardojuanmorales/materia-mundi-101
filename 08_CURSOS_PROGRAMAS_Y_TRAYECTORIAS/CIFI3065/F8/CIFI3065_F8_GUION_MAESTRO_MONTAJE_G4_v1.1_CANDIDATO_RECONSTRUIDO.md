# 0. Propósito

Este documento es el instrumento operativo acumulativo para montar Materia Mundi en G4. No es un resumen de F8 ni una cápsula de QA. Toma el microdiseño profundo U1–U15 de F4 H5 y lo eleva a granularidad de montaje mediante las decisiones aprobadas en F5, F6, F7 y F8 H2–H5.

Debe permitir que una persona pueda abrir el LMS y saber:

`qué crear → dónde ubicarlo → qué debe ver/hacer el estudiante → qué evidencia produce → cómo se evalúa → qué feedback recibe → cómo continúa → qué recursos necesita → qué alternativas debe ofrecer → qué tecnología puede usar → qué debe probarse → qué puede quedar pendiente sin rediseñar`.

Principios rectores:
- integrar antes que añadir;
- REC primero, medio después;
- la carga es techo, no meta;
- PROEMA es una investigación longitudinal única;
- U2/U13/U14/U15 son sistemas funcionales, no cursos paralelos;
- accesibilidad al mismo rigor;
- presencia por función y oportunidad;
- tecnología mínima suficiente;
- IA no es oráculo ni sustituto de autoría;
- G4-B/C no se confunden con G4-A;
- F9 observa comportamiento real, F8 verifica implementación.

# 4. Patrones transversales de montaje

## 4.1 Foro H1–H10
Cada foro debe declarar:
`problema/pregunta → fuente/evidencia → razonamiento esperado → aportación sustantiva → función del contraste entre pares → criterio visible → valor 3.5 → relación FEHE/REC/PROEMA → feedback → destino posterior`.

No existe cuota universal de respuestas sin función académica.

## 4.2 REC
Progresión:
`observar → registrar → transformar → medir → cuantificar → clasificar/representar → modelar → inferir → instrumentar → evaluar consecuencias`.

Ficha base:
1. experiencia/observación;
2. evidencia personal;
3. afirmación/interpretación;
4. límite/incertidumbre;
5. decisión/mejora;
6. apreciación/metacognición.

Rúbrica base 2 puntos:
- 1 punto evidencia + descripción;
- 1 punto razonamiento + límite + mejora/prueba.

## 4.3 PROEMA
`tema común → subtema grupal máx. 3 → contribución individual → E1 H1 → E2 H4 → E3 H7 → E4 H10 → E5 U13 → presentación grupal U14 → artículo individual U15`.

Los nodos intermedios solo hacen micro-movimientos reutilizables.

## 4.4 Feedback
Cadena:
`evidencia → criterio → feedback → revisión/transferencia → nueva evidencia`.

Escala sostenible:
`cohorte → grupo → individuo`.

## 4.5 Recursos
Jerarquía estudiantil visible:
- Núcleo: necesario;
- Profundización: amplía/apoya sin obligación automática;
- Exploración: opcional.

Registro:
`ID → unidad → jerarquía → título/tipo → función → procedencia → licencia/uso → enlace/localización → accesibilidad → contingencia → estado → decisión pendiente`.

## 4.6 Accesibilidad/equivalencia
`barrera → alternativa → REC → criterio → función → autoría → dignidad → prueba`.

Revisar según pertinencia: estructura/encabezados, teclado/foco, contraste, texto alternativo, subtítulos/transcripción, alternativa a visualidad exclusiva, enlaces descriptivos, archivos utilizables e instrucciones multimodales.

## 4.7 Tecnología/IA/privacidad
Tecnología:
`función → REC → ventaja → barrera → datos → dependencia → portabilidad → contingencia → soporte → decisión`.

IA:
`uso permitido → límite → autoría humana → verificación → transparencia/atribución → datos → alternativa sin IA → contingencia`.

Privacidad:
`dato mínimo → propósito explícito → exposición mínima → alternativa razonable`.

### Función y transformación
Portal longitudinal de orientación académica, social, metodológica, ética y organizativa.

Pregunta: **¿Dónde estoy, cómo funciona este mundo y cómo participo responsablemente en él?**

`desorientación potencial → mapa mental del ecosistema → participación informada`.

### Montaje LMS
**Ubicación:** S1 + acceso persistente S2/S5.  
**Secuencia:** bienvenida/presencia → mapa H1–H10/U1–U15 → evaluación 75/25 → rutas PROEMA/REC/DR → lectura guiada del sílabo/prontuario → mini-casos integridad/IA → foro social con propósito → baseline anónimo/huella inicial PROEMA → cierre/reentrada.

- foro de presentación con función de pertenencia/orientación;
- mini-decisión integridad/IA;
- huella inicial de interés/pregunta PROEMA.

### Evaluación/feedback
No crear nueva familia pesada. Feedback principal de cohorte sobre estructura/expectativas; individual solo ante acceso o situación particular.

### Recursos
**Núcleo:** sílabo/prontuario, mapa del curso, tabla evaluación, política IA, guía de ayuda.  
**Profundización:** guía adicional de herramientas o ejemplos.

### Accesibilidad
Mapa visual + versión textual equivalente; encabezados correctos; navegación predecible; enlaces descriptivos; política IA en formato utilizable.

### Tecnología/contingencia
El mapa no puede depender de una visualización única. Si falla elemento interactivo, versión lineal conserva función.

### Carga
225–235 / 270 min. Reactivaciones posteriores sin entregas nuevas.

### Estado G4

## U14 — Taller de Producción Intelectual PROEMA

### Función
Transformar investigación en conocimiento original comunicable, revisable y defendible y preparar tránsito grupo→autoría individual.

Pregunta: **¿Cómo convertir investigación en una comunicación que haga más clara la evidencia y no la esconda detrás de forma o tecnología?**

### Montaje
`audiencia/propósito → arquitectura de argumento → selección evidencia → prototipo → revisión/co-evaluación funcional → presentación grupal → defensa → mapa de contribuciones → preparación artículo U15`.

### Evaluación
Presentación grupal = **15 puntos**. Prototipo/revisión son andamiaje, no nueva familia evaluativa.

### Autoría
Distinguir trabajo común, contribución individual, decisiones compartidas y coordinación. Presentación grupal no borra autoría individual.

### Feedback
Grupo PROEMA; cohorte por patrones; individual para transición autoral.

### Accesibilidad
Formatos equivalentes de comunicación cuando preservan criterio; presentación y visualizaciones accesibles.

### Tecnología
Herramienta elegida por función, no por novedad. Debe existir ruta alternativa si el medio falla.

### Carga
295–315 / 360 min.

### Estado/QA
Rúbrica/flujo/criterios **G4-B**; herramienta/formato final **G4-C**. VD8-03/06/07/10/14; CP7-07.

## U15 — Centro de Integración, Evidencias, Metacognición y Cierre

### Función
Hacer visible la trayectoria completa sin duplicar físicamente tareas. Culmina artículo individual, DR5, portafolio acumulado y lectura metacognitiva.

Pregunta: **¿Qué he producido, cómo cambió mi manera de conocer la materia y qué evidencia permite demostrarlo?**

`colección de entregas → trayectoria legible → autoría individual + metacognición + cierre`.

### Montaje
`panel de trayectoria → selección/localización de evidencias → lectura REC/Lab acumulada → artículo individual → DR5 integrado → autoevaluación/metacognición → instrumento F9 de bajo peso/no punitivo → cierre y retorno al mapa U1`.

### Regla CP7-05
No solicitar reentrega masiva. El panel enlaza/recupera evidencia ya existente.

### Evaluación
- artículo individual PROEMA = **10 puntos**;
- DR5 integrado;
- portafolio REC ya acumulado;
- señales F9 no se convierten en calificación sustantiva.

### Feedback
Principalmente individuo para autoría del artículo; cohorte recibe síntesis final.

### Accesibilidad
Fuente única de orientación, navegación accesible, recuperación perceptible del feedback, equivalentes expresivos preservando autoría/criterio. Cartografía no exclusivamente visual.

### Tecnología/contingencia
El panel debe ser portable o reconstruible mediante enlaces/lista estructurada. Si falla visualización, la memoria del curso no desaparece.

### Carga
350–370 / 420 min.

### Estado/QA
