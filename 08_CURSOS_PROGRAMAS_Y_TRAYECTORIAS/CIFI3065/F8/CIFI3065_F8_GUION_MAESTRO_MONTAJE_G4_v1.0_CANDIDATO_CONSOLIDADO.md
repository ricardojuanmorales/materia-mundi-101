## 1. Función

Este Guión consolida las capas H2–H5 en un único instrumento de montaje y verificación. No sustituye los documentos especializados; los orquesta.

Cadena maestra:
`qué crear → dónde vive → función → acción estudiantil → evidencia/REC → criterio → evaluación/feedback → interacción/presencia → acceso/equivalencia → recurso/medio → tecnología/datos → contingencia → prueba → estado G4 → decisión pendiente`.

## 2. Contrato Maestro G4

Cada objeto registra, según pertinencia:
`ID → fuente canónica → unidad/superficie → función → acción estudiantil → entrada → contenido/tipo → REC/evidencia → criterio → valor/categoría → rúbrica → feedback/destino → interacción → presencia → ubicación LMS → jerarquía de recurso → accesibilidad/equivalencia → autoría → tecnología/datos/IA → procedencia/licencia → contingencia → dependencia → estado G4-A/B/C → evidencia EO → pruebas PH2–PH5/P8 → VD8 → CP7/G7 → QM-B → decisión pendiente → criterio de sustitución`.

## 3. Superficies LMS

S1 entrada/orientación; S2 mapa/recorrido; S3 unidades H1–H10; S4 trayectorias longitudinales PROEMA/REC/DR; S5 cierre U15 y recuperación.

La navegación debe permitir localizar dónde estoy, qué problema importa, qué hago, qué evidencia produzco/recupero, cómo sé si cumple y qué ocurre después.

## 4. Gramática histórica adaptable H1–H10

`orientación → problema → FEHE → fuente/evidencia → puerto adaptativo → experiencia/laboratorio → REC → foro/interacción → PROEMA cuando aplica → recursos → medios → continuidad → QA`.

La intensidad puede variar; la gramática permanece reconocible.

## 5. Puertos adaptativos

Ruta común robusta con movilidad reversible. Apoyo puede añadir guía, contexto, ejemplo, glosario o preparación. Profundización puede añadir contraste, segunda fuente, controversia o pregunta transdisciplinaria.

Por defecto se preservan mismo REC, función, criterio esencial, valor y dignidad académica. No se etiquetan estudiantes de forma fija.

## 6. FEHE y evidencia histórica

La presentación/interfaz FEHE orienta espacio histórico, tensiones, actores, categorías y objetos sin sustituir el encuentro con evidencia primaria. La fuente primaria debe tener procedencia, pertinencia, legibilidad, licencia/uso, accesibilidad y vínculo con REC/evidencia.

## 7. Evaluación 100 / 75–25

Clase 75: foros 35; PROEMA E1–E5 10; presentación grupal 15; artículo individual 10; DR Clase/Investigación 5.

Laboratorio 25: REC/Laboratorios 20; DR Laboratorio/Investigación 5.

Regla: 75/25 es equivalencia operacional provisional del piloto, no modificación institucional.

Todo objeto evaluado declara evidencia, criterio visible, instrumento proporcional, feedback, recuperación, destino y vista estudiante/docente.

## 8. Interacción y presencia

Foros H1–H10 declaran problema, evidencia, razonamiento, aportación sustantiva, función social, criterio, valor, feedback y destino. No existe cuota universal vacía.

Presencia docente: cohorte, grupo e individuo según función y necesidad. Presencia suficiente y oportuna, no omnipresencia.

## 9. PROEMA

`tema → subgrupo → contribución individual → E1 → E2 → E3 → E4 → E5 → presentación grupal → artículo individual → U15`.

Cada estado explicita qué conserva, revisa, añade, qué feedback recupera, qué decisión cambia y qué prepara. No se reinicia la investigación.

## 10. REC

`observar → registrar → transformar → medir → cuantificar → clasificar/representar → modelar → inferir → instrumentar → evaluar consecuencias`.

Cada REC deja evidencia, interpretación, límite/incertidumbre, decisión, feedback y conexión posterior. REC precede al medio.

## 11. H1 / H10 / U15

H1 se monta como secuencia integrada, no pila de tareas. H10 distingue entrega principal, lentes U2/U13/U14, criterios, apoyos y evidencia reutilizada. U15 cosecha, organiza e integra evidencia previa y feedback, evitando reentrega masiva.

## 12. Recursos

Jerarquía estudiantil inequívoca: Núcleo, Profundización, Exploración. Cada recurso registra función, procedencia, licencia/uso, enlace/localización, accesibilidad, contingencia y estado de verificación.

## 13. Accesibilidad y equivalencia

Contrato:
`barrera → alternativa → REC → criterio → función → autoría → dignidad → prueba`.

Revisar estructura, teclado/foco, contraste, texto alternativo, subtítulos/transcripción, alternativas a visualidad exclusiva, enlaces, archivos e instrucciones multimodales según pertinencia.

## 14. Tecnología, IA, datos y contingencia

Tecnología:
`función → REC → ventaja → barrera → datos → dependencia → portabilidad → contingencia → soporte → decisión`.

IA:
`uso permitido → límite → autoría humana → verificación → transparencia/atribución → datos → alternativa sin IA → contingencia`.

Privacidad: dato mínimo, propósito explícito, exposición mínima y alternativa razonable.

Si falla el medio, la función pedagógica y el REC deben sobrevivir.
