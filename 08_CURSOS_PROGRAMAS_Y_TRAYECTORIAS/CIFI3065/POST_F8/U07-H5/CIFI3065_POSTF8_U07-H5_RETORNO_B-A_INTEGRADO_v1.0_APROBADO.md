## 6. Aprendizajes absorbidos

### Transportables / reforzados

1. Reutilizar evidencia antes de multiplicar tareas o datasets.
2. Mantener una operación cognitiva principal por superficie cuando ello reduzca carga extrínseca.
3. Una misma evidencia puede circular por varias superficies si cambia la operación cognitiva:
   `reconstruir → reorganizar/cuantificar → interpretar/modelar/reconocer límite`.
4. La simetría estructural entre unidades debe conservar función y navegación, no copia literal.
5. Distinguir explícitamente:
   `dato histórico / dato docente idealizado / reconstrucción didáctica / notación moderna de apoyo / inferencia-modelo`.
6. Las fórmulas y representaciones pueden funcionar como **modelos candidatos dependientes de supuestos**, no como datos autoevidentes.
7. Mayor densidad histórica puede reducir carga cuando reutiliza actores, relaciones y corpus ya conocidos y cambia la operación cognitiva.
