## 1. Transportables

1. Cuantificación progresiva: `localizar → extraer → organizar → calcular → comparar → interpretar`.
2. Cuando extraer/organizar datos es parte del razonamiento, no entregar al estudiante la relación decisiva ya prefabricada.
3. Distinguir parte y sistema cuando la frontera del sistema cambia el significado del balance, conservación o conclusión.
4. Una misma evidencia puede reutilizarse en actividad, interacción, laboratorio, REC y PROEMA si cada superficie añade una operación cognitiva distinta.
5. Distinguir de forma explícita evidencia histórica, recreación didáctica, dato experimental, dato docente y material sintético.

## 2. Reforzados

- no fabricar ruido/error que el recurso no produce;
- incertidumbre con procedencia plausible;
- proveniencia explícita;
- economía cognitiva y no proliferación de tareas;
- DME estricto `PRODUCIDO → MONTADO → VERIFICADO-SITUADO`;
- nuevas fuentes requieren asiento formal de Carril A;
- equivalencia accesible por función cognitiva, rigor, criterio y destino epistemológico.

## 3. Preferentes condicionados

### Sistema abierto → sistema cerrado

Secuencia valiosa cuando la **frontera del sistema** es parte del problema epistemológico. El sistema abierto puede revelar una limitación y el cerrado responder metodológicamente a ella. No se convierte en patrón obligatorio para otros laboratorios.

### Medio documental con función cognitiva

Combinar video cualitativo con documento visual anotado puede ser eficaz cuando:

- cada medio cumple una función cognitiva distinta;
- hay ruta accesible equivalente;
- el cambio de medio reduce, no aumenta, carga extrínseca.
