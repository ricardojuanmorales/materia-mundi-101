## Dictamen

Se aprueba sin cambio conceptual el Mapa Maestro Longitudinal C2 v0.1.

Queda estabilizada la arquitectura:

`U1 + U2 + U13 ⇄ U14 + U15`

alrededor de una única experiencia de aprendizaje y de la secuencia evaluativa:

`E1/H1 → E2/H4 → E3/H7 → E4/H10 → E5/U13 → presentación grupal → artículo original individual`.

Se ratifican:

- U1 como sistema longitudinal de orientación, navegación, ayuda y recuperación;
- U2 como esqueleto epistemológico integrador;
- U13 como sistema longitudinal de metodología e investigación PROEMA;
- U14 como sistema longitudinal de producción intelectual, tecnología, IA responsable y comunicación;
- U15 como sistema longitudinal de evidencias, memoria, feedback, metacognición e integración;
- transferencia simétrica reversible U13⇄U14;
- artículo original como culminación conjunta U13×U14;
- principio de intensidad variable;
- principio `complejidad ↑ + autonomía ↑ + andamiaje ↓ + carga global ≈ estable`;
- diferencia entre orden de montaje, orden cronológico y función longitudinal;
- principio de experiencia estudiantil simple sobre infraestructura sistémica compleja.

Se autoriza C3 — Arquitectura mínima conjunta U13⇄U14.
