## Estrategia mínima de esta sesión

F4 se ejecutará con el menor número razonable de hitos:

### Hito 1 — Activación y control documental

- archivar el README de apertura;
- actualizar este README como puerta operativa de F4;
- registrar formalmente la activación de la sesión;
- confirmar HEAD y acoplamiento del corpus.

### Hito 2 — Patrón mínimo de microdiseño

Definir una plantilla reusable suficientemente pequeña para gobernar los OVAt sin crear burocracia. Debe cubrir, como mínimo: identidad, propósito REC, evidencia, secuencia, recursos, interacción, laboratorio cuando aplique, PROEMA cuando aplique, DUA, gobernanza Humano/Máquina/IA, feedback, evaluación, carga, LMS y verificación.

### Hito 3 — OVAt representativo y calibración

Microdiseñar **U3/H1** como prueba representativa, porque concentra historia/FEHE, REC, foro, laboratorio, Ensayo PROEMA 1, DR1, DUA, interacción y una semana amarilla de carga. La calibración comprobará:

- alineación REC ↔ evidencia ↔ actividad ↔ evaluación;
- carga realista;
- DUA y accesibilidad;
- interacción y feedback sostenible para N=27;
- integración de foro/laboratorio/PROEMA/DR sin duplicación;
- viabilidad de la Ficha REC como gramática longitudinal reusable.

### Hito 4 — Gate humano de patrón y cierre F4 de sesión

Someter el patrón y el OVAt piloto a decisión humana. Si el patrón pasa, documentar su aprobación, registrar brechas residuales y dejar preparado el mecanismo de escalamiento. No producir los otros 14 OVAt en esta sesión salvo autorización humana explícita posterior.

## Criterios de salida de la sesión

La sesión puede considerarse exitosa si deja:

1. gobernanza documental F4 limpia y verificable;
2. patrón mínimo reusable;
3. un OVAt representativo completamente microdiseñado;
4. calibración REC/carga/DUA/interacción documentada;
5. decisión humana sobre el patrón;
6. estado, bitácora y brechas actualizados para continuidad.

## Regla de eficiencia

Cada artefacto nuevo debe cumplir una función única. Si una necesidad puede resolverse integrando, enlazando o reutilizando una estructura existente, no se crea otra capa documental o actividad.
