## 3. Hallazgo central

`cuantificar ≠ recibir números`

La cuantificación adquiere valor epistemológico cuando el estudiante puede reconstruir:

`qué se midió → cómo se definió el sistema → qué relación se construyó → qué predicción se contrasta → qué afirmación queda respaldada → qué límite permanece`.

## 4. Reglas resultantes

1. Si la extracción y organización de datos forman parte del objetivo, no entregar la comparación decisiva ya construida.
2. Todo balance debe declarar qué cuenta como sistema y qué queda fuera de él.
3. Diferenciar masa de una parte de masa del sistema cuando esa distinción determine la inferencia.
4. Profundizar la misma evidencia antes de multiplicar tareas o datasets.
5. Etiquetar explícitamente la naturaleza de la evidencia: histórica, experimental, docente, sintética, recreación o secundaria.
6. No atribuir a una recreación didáctica el estatuto de reproducción histórica literal sin evidencia suficiente.
7. Conservar procedencia y función de la incertidumbre; no usar “error” como decoración realista.

## 5. Patrones preferentes condicionados

### Sistema abierto → sistema cerrado

Usar cuando la frontera del sistema sea el núcleo del problema. El primer estado revela una insuficiencia interpretativa y el segundo permite responder a ella mediante mejor control. No trasladar mecánicamente a otras unidades.

### Video cualitativo + documento visual anotado

Puede emplearse cuando separa con claridad observación de cambio, reconstrucción de procedimiento y lectura de datos. Debe existir equivalencia accesible y el cambio de medio debe cumplir función cognitiva explícita.

## 6. Límite de generalización

No se transfieren como universales Priestley/Lavoisier, combustión, calcinación de cobre, videos, Foto Ensayo, datos concretos, valores, imágenes, copy ni secuencia técnica exacta de H4.
