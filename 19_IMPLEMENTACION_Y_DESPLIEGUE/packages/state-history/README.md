# State History + Evidence

Patrones compartidos para aplicaciones de Materia Mundi.

## Historial semántico
- conserva hasta N estados previos;
- cada entrada tiene etiqueta y fecha;
- permite undo sin registrar cada pulsación de teclado;
- el consumidor decide qué acciones merecen checkpoint.

## Evidencia
- convierte un registro de decisiones y secciones finales en Markdown;
- no impone contenido disciplinario;
- puede reutilizarse por H6 y futuras apps.

Principio: **registrar decisiones, no ruido de interfaz**.
