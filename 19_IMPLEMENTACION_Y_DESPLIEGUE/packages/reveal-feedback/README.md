# Reveal + Feedback Engine

Motor compartido para revelaciones y retroalimentación de Materia Mundi.

## Objetivo

Centralizar **cuándo aparece información** y **cómo se formula la retroalimentación** sin añadir controles ni pasos al estudiante.

## Tipos de feedback

- descriptivo;
- interrogativo;
- histórico.

## Principio

El motor no corrige prematuramente ni declara una “respuesta correcta” durante la exploración. La retroalimentación debe orientar atención, provocar revisión y preservar la agencia del estudiante.
