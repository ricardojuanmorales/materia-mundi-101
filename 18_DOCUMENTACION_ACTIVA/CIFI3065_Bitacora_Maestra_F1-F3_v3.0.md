## Aprendizajes de sesión que actualizan la gobernanza

1. **La pausa estratégica puede ser una unidad de diseño:** si revela que el modelo mental es incorrecto, debe preceder a la escritura aunque exista una candidata funcional.
2. **Una autorización puede abarcar una unidad coherente de varias escrituras** cuando el alcance ha sido explicitado y todas las escrituras sirven al mismo estado semántico.
3. **Verificar después de escribir:** se releyeron productos críticos desde GitHub antes de presentarlos como completos.
4. **No reintentar ciegamente:** un borrado F3-B v1.0 falló por SHA obsoleto; se releyó el blob actual y se repitió sólo con evidencia fresca.
5. **Git puede ser la terminal invisible:** operaciones de lectura, creación, actualización, borrado, inspección de commits y verificación se realizaron mediante conexión GitHub sin terminal local.
6. **Una candidata puede ser descartada legítimamente:** F3-B v1.0 fue retirada del árbol activo y preservada por la genealogía Git al ser superada por v1.1.
7. **Estado semántico antes que proliferación:** versiones nominales nuevas se reservan para cambios de fase, Gates o sustituciones justificadas.
