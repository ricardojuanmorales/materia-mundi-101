# Gate MIG-F3 — Prueba de Continuidad
Una nueva sesión pasa el Gate si, usando el paquete canónico, reconstruye correctamente:
- identidad y propósito de Materia Mundi;
- F1/F2 cerradas y último Gate H2.8;
- fase siguiente F3;
- condiciones C-F3-01–08;
- herencias H1–H10/FEHE, RIA/REC/PSEC/evaluación;
- brechas activas y destinos;
- frontera F3 vs F4;
- próximo movimiento permitido;
- autoridad humana para decisiones de alto impacto.

## Resultado
- [ ] PASS → abrir F3.
- [ ] PASS CON AJUSTES → corregir Primer/Estado y repetir.
- [ ] FAIL → no abrir F3; reparar paquete.
